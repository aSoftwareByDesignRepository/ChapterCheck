<en-US>
First public ChapterCheck release for Linux.

• Link local folders for audiobooks and music
• Resume progress, variable speed, and a process-level sleep timer
• Dark-friendly UI with clear play vs details controls
• Optional online metadata only after an OS confirm dialog
• Playback via mpv · no ads · no analytics
