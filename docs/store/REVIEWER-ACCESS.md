# Reviewer access — ChapterCheck

No account, pairing code, or demo server is required.

## How to test (5 minutes)

1. Install from the submitted Flatpak / Snap / `.deb`.
2. Launch **ChapterCheck**.
3. On first run: **Add my folder** → pick a folder with a few `.mp3` / `.m4b` files (reviewers may use any short sample audio).
4. Tap play on a title; scrub; change speed; open sleep timer and start a short preset.
5. Optional: Prefs → appearance (dark/light); leave online metadata **off** unless testing the OS confirm dialog.

## What reviewers should not expect

- Cloud login or Nextcloud credentials (that is **AudioCheck**)
- Bundled sample audiobooks in the package
- Windows / macOS builds in this release line
